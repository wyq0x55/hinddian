# 构建章节试读

- [第一阶段排障章节](chapters/hinddian/session-bd01fb50099ed76f755b33b7.md) 记录了旧草稿冒烟验证失败、切换验证方式的依据、三种宿主的复测结果以及未决项。来源是 [hinddian 转型第一阶段会话](t3-thread://v2/31b1bbaa-8828-41e4-b0be-3fb0e9f77d39/mcp:f0e2bca4-255d-4318-8db6-8d30501a8ce0)。
- [短任务对照](chapters/short-control/session-0d21e1747859cacc6c062ddd.md) 使用合成的 README 修改任务。

两份样例都用实际插件 `Stop`、后台整理入口和固定模型响应生成。排障输入选录了第一阶段会话中与验证相关的消息。只出现在工具输出里的错误和修改依据由人工摘录，条目内标注了原会话行号。常规采集会过滤工具输出，Agent 若在可见进展里说明失败及依据，章节便能引用该消息。

笔记顶部链接到各自的脱敏记录。在 JSON 中搜索 `@` 左侧的位置即可找到对应消息，`@` 右侧给出该片段在消息里的起始字符。试读版来源文件保留会话 ID、位置和正文，省略本地采集游标。`tests/test_chapters.py` 会重放两份 fixture 并对照这里的产物。
