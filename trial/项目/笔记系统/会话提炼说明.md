# 会话如何进笔记（现行）

> **2026-10-18 改写**。旧「OTLP Full content → 待入库 → DECISIONS/LESSONS」主路径已停用。权威：仓库 [`docs/PIPELINE.md`](https://github.com/wyq0x55/hinddian/blob/main/docs/PIPELINE.md)。

## 主路径（hooks + 会话桶）

1. **turn-end**：白名单抽取（用户话 + 最终助手回复）→ 本机会话缓冲（不按回合推远程）
2. **finalize**（下次开会话 / 空闲约 30 分钟 / 换项目）：本机 Jev keep → 一次 `push_draft`
3. **草稿**：`/var/lib/hinddian/drafts/<项目>/session-*.md`（不是 vault `待入库/`）
4. **batch（vault 主机）**：新项目满 20 条会话草稿 → 仪表盘批准；已批准增量自动；技巧可自动
5. **原子笔记**写入 Obsidian → **hindsight-sync** 更新索引

Jev 写路径：本机 Magpie `:3425/v1/systemone` → 可选云端 TypeSafe → 失败则 **不记**（`source=none`）。

## Agent 显式修正

- `upsert_note`（门控）或 `suggest_correction` → 仪表盘「Agent 修正」
- 禁止 Hindsight `retain`；禁止硬删（用 supersede/obsolete）

## Magpie 安装提醒

WebDAV **不同步 Hooks**。Windows：

```powershell
magpie webdav now
& "$env:USERPROFILE\.config\magpie\library\skills\hinddian-hooks\install.ps1"
```

## 历史路径（归档说明）

OTLP inbox / `项目/*/待入库/` / 大文件三件套合并，仅作历史；`otel.enabled=false`。补历史会话请走运维脚本，不要当默认产品路径。
