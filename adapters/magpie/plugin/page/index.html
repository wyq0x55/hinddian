Hindian 记忆

把 hinddian-memory MCP 和 Magpie Library Hooks（session-start / turn-end）装到本机。

硬限制：Magpie WebDAV / 备份 不同步 Hooks；插件启用也不会自动写入 Hooks。每台电脑装一次。

推荐（像市场一样）

  1. Magpie → Library → Skills → 粘贴 wyq0x55/hinddian → 安装 hinddian-hooks
  2. Windows PowerShell 执行：
magpie webdav now
& "$env:USERPROFILE\.config\magpie\library\skills\hinddian-hooks\install.ps1"

或对任意 Agent 说：安装 hinddian（若已启用本插件工具）。

插件安装

magpie plugin add github:wyq0x55/hinddian
# 然后让 Agent 调用 hinddian_install，或手动跑上面的 install.ps1

私有仓库需在 Magpie Settings 填 GitHub token。

装好后检查

  • Library → Hooks：hinddian-session-start、hinddian-turn-end
  • Library → MCP：hinddian-memory

不要在其他电脑跑 apply_library.py（SoT 在 vault 主机）。
